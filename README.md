# Expense Tracker

A full-stack expense tracking web application built using React, Express, PostgreSQL, and JWT authentication.

## Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Authentication
- JWT
- bcrypt
