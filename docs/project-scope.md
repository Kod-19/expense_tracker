# Project Scope

## Objective

The goal of this project is to build a personal expense tracker that helps users monitor money coming in and going out.

## In scope

- user sign up and login
- user profile support
- category management for income and expenses
- secure API routes
- database and Supabase integration
- frontend and backend project setup
- basic documentation for the project

## Out of scope for now

- full transaction management
- dashboard charts and analytics
- recurring budgets
- notifications and reminders
- export to CSV or PDF
- multi-user admin features
- payment integrations

## Current maturity level

This project is at the base setup and API stage. The backend has core auth and category features, while the frontend is still a starter screen.

## Project focus

The current focus is on building a strong foundation:

- clean backend structure
- secure authentication
- working API routes
- database design
- simple project documentation

## Final goal

The finished app should let a user manage their personal finances in a clear and useful way without needing advanced technical knowledge.
