# Requirements

This project is a personal expense tracking app. The main goal is to help users keep track of money they earn and spend in a simple and organized way.

## Functional requirements

1. Users can create an account with an email, password, and full name.
2. Users can sign in to the app securely.
3. The system should store the user profile information.
4. Logged-in users can create income and expense categories.
5. The API should return a clear success or error message for each request.
6. The system should protect private routes so only logged-in users can access them.

## Non-functional requirements

1. The application should be easy to use.
2. The API should respond quickly and clearly.
3. The app should support secure authentication.
4. The code should be organized into frontend and backend folders.
5. The app should work well in a local development environment.

## Current implementation scope

The current project already includes:

- user registration
- user login
- user profile lookup
- category creation
- API health checks

## Planned future scope

The app can later include:

- transaction entries
- monthly reports
- charts and analytics
- expense filters
- edit and delete actions
- dashboard summary pages

## Summary

The main requirement is simple: a user should be able to manage their money in a clean, secure, and easy-to-understand system.
